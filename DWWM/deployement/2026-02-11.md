# Test unitaire 
- *test unitaires* => "qu'est ce qu'on attend que le code va faire" , personne aime ca mais important pour le CI/CD. 60% = bonne application.  il y a plusieurs echelons:
	- test unitaire/test composant : tests les differents composants TU crées (pas natif)
	- tests d'integration : tests fonctionnalités pour savoir si elles marchent. verifie les fonctionnements entre les fonctionnalitées 
	- tests systeme : infrastrucutre qui l'a gère 
	- test d'acceptation : test utilisateurs clients (retour des clients)
