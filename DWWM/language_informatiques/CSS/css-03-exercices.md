# 📝 Exercices CSS

## Exercice 1 — Texte et couleurs

**Objectif :** mettre en forme du texte.

### HTML

`<p class="text">   Bonjour le CSS </p>`

### Consignes

1. Mettre le texte en bleu
    
2. Augmenter la taille du texte
    
3. Centrer le texte horizontalement
    

---

## Exercice 2 — Box model

**Objectif :** comprendre `margin`, `padding`, `border`.

### HTML

`<div class="box">   Contenu </div>`

### Consignes

1. Ajouter une bordure noire de 2px
    
2. Ajouter un espace intérieur de 20px
    
3. Ajouter un espace extérieur de 30px
    

---

## Exercice 3 — Mise en page Flexbox

**Objectif :** aligner des éléments horizontalement.

### HTML

`<div class="container">   <div class="item">A</div>   <div class="item">B</div>   <div class="item">C</div> </div>`

### Consignes

1. Afficher les items sur une ligne
    
2. Espacer les éléments équitablement
    
3. Centrer les éléments verticalement
    

---

## Exercice 4 — Carte simple

**Objectif :** combiner plusieurs propriétés.

### HTML

`<div class="card">   <h2>Titre</h2>   <p>Description de la carte</p> </div>`

### Consignes

1. Ajouter un fond blanc
    
2. Arrondir les coins
    
3. Ajouter une ombre légère
    
4. Limiter la largeur à 300px
    

---

## Exercice 5 — Responsive

**Objectif :** adapter le style à la taille d’écran.

### Consignes

1. Taille du texte normale sur grand écran
    
2. Réduire la taille du texte si l’écran fait moins de 768px
