

# Qu'est ce que c'est node.js


- c'est un environnement d'exécution javascript
- il fonctionne avec un moteur V8
- il permet d'utiliser javascript du coté serveur 
- fonctionne de façon asynchrone ( + rapide )
- dispose d'une bibliothèque gigantesque 
- idéal pour les projet en temps réel comme les chats 
- pratique pour les Api REST
		REST = nomenclature, même nommage des méthodes

# NPM

- bibliothèque de paquets pré - construit 
- permet de tester les fichiers 
- dépendance de Node.js
- Facilite le développement 
- Conçu pour et par Node.js

``` js
npm init 
npm install express
npm uninstall express
npm run
```

# Exposé sur node.js et npm

## 🎤 Résumé oral — Node.js & npm

> _Node.js est un environnement qui permet d’exécuter du JavaScript en dehors du navigateur, directement côté serveur. Il est basé sur le moteur V8 de Chrome, ce qui le rend rapide._

> _Node.js fonctionne de manière asynchrone avec une boucle d’événements. Même s’il est **monothread** , il peut gérer beaucoup de connexions en même temps sans bloquer l’exécution, ce qui le rend très adapté aux applications réseau._

> _Il fournit de nombreux modules intégrés, comme fs pour les fichiers ou http pour créer un serveur web, ce qui permet de développer des applications sans dépendances externes._

> _Node.js est souvent utilisé pour créer des API, des serveurs web, des applications temps réel comme des chats, ou encore des outils en ligne de commande._

> _npm, qui est installé avec Node.js, est le gestionnaire de paquets. Il permet d’installer, mettre à jour et gérer les bibliothèques nécessaires à un projet._

> _Les dépendances et les scripts sont définis dans un fichier package.json, ce qui facilite le partage et la maintenance des projets._

> _En résumé, Node.js permet d’utiliser JavaScript côté serveur, et npm fournit un énorme écosystème de packages. Ensemble, ils sont devenus des outils essentiels du développement web moderne._
