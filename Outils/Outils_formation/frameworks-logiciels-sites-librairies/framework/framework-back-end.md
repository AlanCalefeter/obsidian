 - [NestJs](https://docs.nestjs.com/) : Framework très dur de javascript mais très complet. Fonctionne avec des bases de JAVA

- [Adonis](https://adonisjs.com/) : Framework full-stack riche en fonctionnalités. Il intègre un ORM. Il intègre l'authentification. Des fonctionnalités d'autorisation et de gestion des permissions.

- [ spring boot](https://spring.io/projects/spring-boot) : Java Spring Boot est un outil open source qui facilite l'utilisation d'infrastructures Java pour créer des micro services et des applications web.

- [express](https://expressjs.com/) : Framework léger pour server http. Polyvalent
