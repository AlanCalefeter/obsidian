- [AngularJS](https://angularjs.org/) : framework JavaScript open source, conçu pour créer des applications web dynamiques en Single-Page Application (SPA), ou applications monopages

- [ReactJS](https://react.dev/) : bibliothèque JavaScript frontale à code source ouvert permettant de créer des interfaces utilisateur ou des composants d'interface utilisateur

- [VueJS](https://vuejs.org/guide/introduction) librairie JavaScript open source utilisée pour construire des interfaces utilisateur (UI) et (SPA)
